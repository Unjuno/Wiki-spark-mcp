03 / The toolkit

Four tools.
One clear boundary.

読み取り専用Wikipedia MCP。出力は参考コンテキストで、自動実行や最終提案をしません。

⌕

wiki_search

検索し、記事名・短い抜粋・出典URLを返す。

↗

wiki_read

導入部と正規URL、利用可能な版情報を取得。

⁕

wiki_random

1〜4件を抽出。取得不足は complete=false。

✳

wiki_skill

課題・要件・記事を一時スキルにまとめる。

05 / Start locally

Your machine.
Your MCP client.

Node.js 20.11以降。ローカルstdio専用。公開HTTPSエンドポイントはありません。

01 — Install

git clone https://github.com/Unjuno/Wiki-spark-mcp.git
cd Wiki-spark-mcp
npm ci --ignore-scripts
npm run check
npm test

外部通信テスト前に、自分が管理する連絡先を設定。

02 — Connect an MCP client

{
  "mcpServers": {
    "wiki-spark": {
      "command": "node",
      "args": ["/absolute/path/src/server.mjs"],
      "env": {"WIKIMEDIA_CONTACT": "https://your-contact-page"}
    }
  }
}

既存設定を上書きせず、パスと連絡先を調整してください。

06 / Security & limitations

Curiosity,
with boundaries.

Wikipediaの記事は信頼境界の外にある非信頼データです。利用側AIでも記事の命令を実行しない制御が必要です。

Read SECURITY.md ↗
読み取り専用ローカルstdio。Wikipedia APIへのGETのみ。
非信頼の資料完全なプロンプトインジェクション防御は保証しません。
公開ブリッジなし認証、利用制限、分離、追加レビューなしで公開HTTP化しないこと。
効果は未保証抽出の一様性、正確性、最新性、妥当性、改善効果を保証しません。
AIなしWikiSparkはLLMを含まず、改善提案を自動生成しません。
出典を保持記事URL、寄稿者表示、履歴・ライセンス案内を維持してください。
