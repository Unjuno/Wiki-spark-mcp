PLAYGROUND

思考のコンテキストを組み立てる

課題に異分野のWikipedia記事を添え、一時的な思考スキルを構成します。記事の取得とプロンプトの生成までを体験できます。

サインインで実通信
Live Playgroundはサインインした利用者向けです。課題文は記事選択には送られず、Wikipediaにも送信しません。秘密情報や個人情報は入力しないでください。AIによる提案生成は行いません。

GET STARTED

ローカル環境で、すぐに始める。

Node.js 20.11以降。MCPサーバーはローカルstdioで動作します。PlaygroundのWikipedia通信は認証付きサイトAPIを経由します。

01 — Install

git clone https://github.com/Unjuno/Wiki-spark-mcp.git
cd Wiki-spark-mcp
npm ci --ignore-scripts
npm run check
npm test

外部通信テスト前に、自分が管理する連絡先を設定。

02 — Connect an MCP client

{
  "mcpServers": {
    "wiki-spark": {
      "command": "node",
      "args": ["/absolute/path/src/server.mjs"],
      "env": {"WIKIMEDIA_CONTACT": "https://your-contact-page"}
    }
  }
}

既存設定を上書きせず、パスと連絡先を調整してください。

SECURITY

安全性と、できることの境界。

Wikipediaの記事は信頼境界の外にある非信頼データです。利用側AIでも記事の命令を実行しない制御が必要です。

Read SECURITY.md ↗
読み取り専用ローカルstdio。Wikipedia APIへのGETのみ。
非信頼の資料完全なプロンプトインジェクション防御は保証しません。
Playground APIサインイン必須。Workerごとに1利用者5回/時を目安とする制限、IP上限、同時実行・入力サイズ制限があります。
効果は未保証抽出の一様性、正確性、最新性、妥当性、改善効果を保証しません。
AIなしWikiSparkはLLMを含まず、改善提案を自動生成しません。
出典を保持記事URL・版情報・寄稿者表示・ライセンス案内を表示します。
サービス制限匿名利用を拒否します。利用制限はWorkerごとのメモリ内で、分散環境全体をまたぐ永続計数ではありません。
