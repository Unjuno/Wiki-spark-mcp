# Changelog

## Site overhaul — 2026-11-07 (MCP remains v0.4.0)

- Add a discovery-first public landing page with Canvas visual, semantic HTML fallback and anonymous Wikipedia browsing.
- Consolidate all five tools into shared operations for stdio MCP, HTTP API and WebMCP.
- Add explicit discovery state reducer and stale-request cancellation.
- Add same-origin, schema, size, concurrency and in-process rate safeguards; document one-replica restriction.
- Add site unit/integration tests and deployment/architecture documentation.


## 0.4.0 — 2026-10-30

- Fix intermittent live-test failures when the first random articles have short excerpts, using a globally bounded random-start retry budget.

- Put Wikipedia article discovery first, with new no-argument `wiki_discover` tool.
- Return one random article, sanitized URL/revision metadata and a language-specific explanation handoff for the calling AI.
- Keep article text separate from explanation instructions and explicitly mark AI explanation as not generated by the server.
- Preserve four existing MCP tools, add deterministic unit and stdio integration coverage, and extend real API smoke tests to five tools in ja/en.
- Document the required website integration without claiming the separate public Sites deployment has been updated.


## 0.3.0 — 2026-10-28

- Correct the SDK v2 stdio lifecycle: `serveStdio` returns a handle, not a Promise.
- Add actual SDK/child-process/stdio integration tests for legacy and 2026-07-28 protocol modes.
- Return `structuredContent` with matching text content and read-only annotations.
- Pin SDK 2.4.0 and commit a generated dependency lockfile.
- Add sequential, bounded HTTP requests, limited caching, Retry-After cooldowns and response validation.
- Deduplicate canonical page IDs; preserve explicit partial results.
- Separate article text from the generated instruction string; attach source identifiers and reuse notices.
- Add live tests for all four tools in Japanese and English; document trust boundaries and setup.

## 0.2.0 — earlier prototype

Added explicit requirements/avoid lists, revision metadata, snapshot hashes and independent random starts. Its offline tests did not validate actual MCP startup; that gap is addressed in 0.3.0.
